## 🌟 نظرة عامة على المشروع

هذا المشروع عبارة عن **تطبيق تعليمي تفاعلي مستقل بالكامل** مصمم وفق أحدث معايير التعليم الاستقصائي (Inquiry-based Learning) والتصميم البصري الأكاديمي عالي التباين والأناقة.

يحتوي الدرس على **10 محطات تعليمية متكاملة**:
1. **عجلة الملاهي (التهيئة الحركية):** محاكاة حية بحسابات فورية لاكتشاف دائرية الدوران وتكرار الارتفاع.
2. **اكتشاف المفهوم والتصنيف:** بطاقات تفاعلية لتصنيف المعادلات المثلثية والمتطابقات والمعادلات الجبرية مع تغذية راجعة فورية.
3. **المعرفة السابقة:** اختبار تفاعلي في حل المعادلات الخطية والتربيعية مع ربط فوري بالمفاهيم القادمة.
4. **مختبر دائرة الوحدة التفاعلي:** محاكاة هندسية حية مع وتر مثلث داكن ومحاور ملونة وزوايا خاصة شائعة (0°, 30°, 45°, 60°, 90°, ...).
5. **التمثيل البياني:** رسم ديناميكي مباشر لمنحنيات الجيب وجيب التمام مع خطوط التقاطع الأفقية واكتشاف الحلول.
6. **خوارزمية الحل المنهجية:** خطوات إرشادية تفصيلية (الزاوية المرجعية، تحديد الأرباع، إشارات النسب).
7. **التدريب المتدرج:** 4 مستويات متدرجة الصعوبة (مباشر، معامل، حدود متعددة، تحليل بالتحليل).
8. **التطبيقات الحياتية (حركة المد والجزر):** محاكاة فيزيائية حقيقية لارتفاع مياه الميناء وحساب أوقات رسو السفن.
9. **التعلم التعاوني:** تحدي المجموعات الأربع مع مساحة لتسليم الحلول والملاحظات.
10. **بطاقة الخروج:** تقييم ختامي واستبيان ثقة وتصدير فوري للدرجات.

## 🔐 لوحة تحكم المعلم وإدارة الصف

لوحة المعلم مخصصة لإدارة الصف وتوجيهه وتتبع نتائج واستجابات الطلبة وتصدير البيانات إلى ملف Excel/CSV.

- **كلمة مرور دخول لوحة المعلم:**  
  `omar@2026`
- **التأمين والتشفير:**  
  كلمة المرور **غير مكتوبة كنص صريح** داخل ملفات HTML أو JavaScript. يتم التحقق منها عبر دالة التجزئة التشفيرية القياسية **SHA-256**:
  `7d9a2871f8ac90850e929924071e371d473f2314a914a2583be6f41fc614df72`
- **ملاحظة أمنية حول النشر على الاستضافات الثابتة (مثل GitHub Pages):**  
  بما أن GitHub Pages هي استضافة للملفات الثابتة (Client-Side Only) دون خادم خاص (Backend Server)، فإن التشفير بـ SHA-256 يمنع أي شخص أو طالب من معرفة كلمة المرور بمجرد فتح كود المصدر (View Source). ومع ذلك، فإن أي تطبيق ثابت يمكن لشخص متقدم التلاعب بذاكرة المتصفح عبر DevTools؛ لذا في حال الرغبة بمصادقة مشددة بنسبة 100% مستقبلاً، يمكن ربط لوحة المعلم بخدمة مصادقة سحابية مثل Firebase Auth.

## 🚀 طريقة النشر المباشر على GitHub Pages

المشروع مصمم ليعمل مباشرة بدون خوادم، وتكفي خطوة رفع الملفات لتشغيله عبر رابط مجاني مدى الحياة.

### الطريقة الأولى: عبر واجهة موقع GitHub (السهلة)
1. سجّل الدخول إلى حسابك على [GitHub](https://github.com).
2. أنشئ مستودعًا جديدًا (New Repository) وسمّه مثلاً: `trig-interactive-lesson`.
3. اجعل المستودع **Public**.
4. اضغط على **"uploading an existing file"**.
5. اسحب وأفلت الملفات التالية من مجلد المشروع (أو من ملف ZIP بعد فك ضغطه):
   - `index.html` (الملف الرئيسي)
   - `.nojekyll` (لمنع معالجة Jekyll في GitHub Pages)
   - `README.md`
   - مجلد `public` أو أي ملفات ملحقة إذا وُجدت.
6. اضغط **Commit changes**.
7. انتقل إلى تبويب **Settings** في المستودع:
   - اختر من القائمة الجانبية **Pages**.
   - تحت قسم **Build and deployment**:
     - اختر **Source**: `Deploy from a branch`.
     - اختر الفرع **Branch**: `main` (أو `master`) والمجلد `/ (root)`.
     - اضغط **Save**.
8. انتظر دقيقة واحدة، وسيظهر رابط موقعك في أعلى صفحة Pages، ويكون على النحو:
   `https://<اسم-حسابك>.github.io/trig-interactive-lesson/`

### الطريقة الثانية: عبر سطر الأوامر (Git CLI)
```bash
# الانتقال لمجلد المشروع
cd trig-interactive-lesson

# تهيئة مستودع جيت
git init
git add .
git commit -m "Initial commit of interactive trigonometry lesson for 10th grade"

# ربط المستودع بحسابك على غيت هاب (استبدل الرابط برابط مستودعك)
git remote add origin https://github.com/<your-username>/trig-interactive-lesson.git
git branch -M main
git push -u origin main
```
ثم تفعيل GitHub Pages من Settings > Pages كما هو موضح أعلاه.
